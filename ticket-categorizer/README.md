# AI Customer Support Ticket Categorizer

## Problem
Support tickets pile up in one queue with no automatic sorting — teams waste time manually reading each one just to figure out what it's about and how urgent it is before it can be assigned.

## What it does
This n8n workflow automatically:
1. Receives a new support ticket
2. Sends the ticket content to an AI model to read and analyze
